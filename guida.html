Requisiti di sistema

  • Windows 10 o Windows 11 (64 bit)
  • Python 3.10 o versione successiva (installato automaticamente dal programma di installazione, se non presente)
  • Connessione a Internet per il primo avvio, la ricerca e il download dei brani
  • Per l'app mobile: dispositivo Android connesso alla stessa rete Wi-Fi del computer

Primo avvio

  1. Avviare Spoopify dal menu Start o dal collegamento sul desktop.
  2. Al primo avvio Spoopify scarica i componenti necessari. L'operazione richiede circa un minuto.
  3. Spoopify si apre nel browser predefinito all'indirizzo http://spoopify.localhost. L'icona di Spoopify viene aggiunta all'area di notifica della barra delle applicazioni.

Chiudendo la scheda del browser, Spoopify resta disponibile nell'area di notifica. Il menu dell'icona, aperto con il pulsante destro del mouse, consente di riaprirlo o chiuderlo.

Libreria musicale

Al primo avvio viene richiesta la cartella della libreria musicale:

  • Crea nuova cartella: crea la cartella Musica\Spoopify.
  • Usa una cartella esistente: utilizza una cartella che contiene già file MP3. Tag, copertine e generi sono salvati nei file e vengono riconosciuti automaticamente.

La cartella è modificabile in qualsiasi momento in Impostazioni > Libreria.

Importare la libreria da un altro computer

Se un altro computer della rete locale utilizza Spoopify, la sua libreria può essere importata senza copiare i file manualmente.

  1. Sul computer di origine, attivare Spoopify Sync da Sincronizza o dal menu dell'icona nell'area di notifica.
  2. Su questo computer, aprire Sincronizza > Ricevi da un altro PC.
  3. Selezionare Cerca, scegliere il computer di origine e quindi Ricevi.

Le importazioni successive trasferiscono solo i brani nuovi o modificati. Gli aggiornamenti di Spoopify vengono scaricati da Internet (vedi Aggiornamenti).

Spoopify per Android

Spoopify per Android sincronizza la libreria sul dispositivo per l'ascolto anche offline. Il dispositivo e il computer devono essere connessi alla stessa rete Wi-Fi.

Installazione tramite codice QR

  1. In Spoopify, aprire Sincronizza nella barra superiore e selezionare Collega un telefono. Viene visualizzata la pagina di Spoopify Sync con un codice QR.
  2. Inquadrare il codice QR con la fotocamera del dispositivo e aprire il collegamento.
  3. Toccare Scarica l'app (APK). Se Chrome segnala che il file potrebbe essere dannoso, toccare Scarica comunque.
  4. Aprire il file scaricato. Se richiesto, consentire l'installazione di app da Chrome, quindi toccare Installa.
  5. Se Google Play Protect segnala un'app non riconosciuta, toccare Installa comunque.

Spoopify per Android è distribuito direttamente e non tramite Google Play: per questo motivo vengono mostrati gli avvisi precedenti.

Installazione manuale

Copiare il file Spoopify.apk sul dispositivo tramite cavo USB e aprirlo dal dispositivo. Il file è disponibile nel menu Start in Spoopify per Android (APK).

Sincronizzazione

  1. Aprire Spoopify sul dispositivo e consentire le notifiche, necessarie per i controlli di riproduzione.
  2. Il computer viene rilevato automaticamente. In alternativa, inserire in Opzioni l'indirizzo mostrato nella pagina di Spoopify Sync.
  3. Selezionare i contenuti da sincronizzare (intera libreria, tag o destinazione) e toccare Sincronizza.

Le sincronizzazioni successive trasferiscono solo le differenze. Spoopify Sync entra in sospensione dopo 10 minuti di inattività e viene riattivato automaticamente dal dispositivo. Per avviarlo insieme a Spoopify, attivare l'opzione Avvia Spoopify Sync con Spoopify in Sincronizza.

Destinazioni

Le destinazioni mantengono una copia filtrata della libreria in un'altra cartella, ad esempio su un'unità USB, una scheda SD o nella cartella musicale di un gioco.

  1. Nella libreria, applicare il filtro desiderato.
  2. Selezionare Esporta > Nuova destinazione. Il filtro attivo viene applicato alla destinazione.
  3. Indicare la cartella con Scegli oppure inserirne il percorso.
  4. Selezionare Sincronizza, verificare le modifiche proposte e confermare.

Spoopify modifica solo i file che ha copiato nella destinazione. Gli altri file presenti nella cartella non vengono modificati.

Generi musicali

Spoopify assegna automaticamente il genere ai brani scaricati. Per un riconoscimento più accurato è possibile utilizzare una chiave API di Last.fm (gratuita, richiede un account Last.fm):

  1. Creare una chiave API su last.fm/api.
  2. In Spoopify, aprire Impostazioni > Download e inserire la chiave in Chiave API Last.fm.

Risoluzione dei problemi

ProblemaSoluzione
Spoopify non si avviaVerificare che sia installato Python 3.10 o versione successiva (Microsoft Store o python.org), quindi avviare di nuovo Spoopify. I dettagli dell'errore sono registrati in soundtrack\soundtrack.log nella cartella di installazione.
La pagina non si apre all'indirizzo spoopify.localhostSe la porta 80 è utilizzata da un altro programma, Spoopify usa l'indirizzo http://spoopify.localhost:8765.
Il dispositivo Android non rileva il computer
  • Verificare che il dispositivo e il computer siano connessi alla stessa rete Wi-Fi.
  • In Windows, impostare la rete come Privata.
  • Se richiesto da Windows, consentire a Python l'accesso alle reti private.
  • Se durante l'installazione non è stata configurata la regola del firewall, eseguire spoopify-android\Apri firewall.cmd come amministratore.
  • Inserire manualmente l'indirizzo mostrato nella pagina di Spoopify Sync.
La finestra di selezione della cartella non è visibileLa finestra potrebbe essere aperta dietro il browser ed è disponibile nella barra delle applicazioni.
Le impostazioni di aspetto (tema, colori, dimensione delle icone) sono salvate nel browser e non vengono trasferite su altri browser o computer.

Aggiornamenti

Spoopify verifica periodicamente la disponibilità di nuove versioni. Quando è disponibile un aggiornamento, nella barra superiore compare il pulsante Aggiorna. La verifica può essere eseguita anche da Impostazioni > Novità > Cerca aggiornamenti.

Ogni aggiornamento è firmato digitalmente e viene installato solo se la firma risulta valida. Prima dell'installazione viene creata una copia di sicurezza, ripristinata automaticamente in caso di errore. Al riavvio, le modifiche introdotte sono riepilogate nella finestra Novità.

Disinstallazione

Aprire Impostazioni di Windows > App > App installate, selezionare Spoopify e quindi Disinstalla. La libreria musicale non viene eliminata.
