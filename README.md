# Spoopify

Lettore e gestore di una libreria musicale MP3 per Windows: ricerca e download dei brani, tag, copertine, generi,
playlist e sincronizzazione con altri computer e con l'app per Android.

Questa pagina contiene esclusivamente le versioni pubblicate del programma.

## Installazione

1. Scaricare il programma di installazione: **[Spoopify-Setup.exe](https://github.com/Daxterminator/Spoopify_Releases/releases/latest/download/Spoopify-Setup.exe)**
2. Avviare il file scaricato. Windows SmartScreen può segnalare un'applicazione non riconosciuta, poiché il programma
   non dispone di un certificato di firma commerciale: selezionare **Ulteriori informazioni › Esegui comunque**.
3. Seguire le istruzioni. Se Python non è presente, viene installato automaticamente.

Al primo avvio Spoopify scarica i componenti necessari (circa un minuto) e si apre nel browser predefinito.
La guida completa è disponibile nel menu Start, alla voce **Guida di Spoopify**.

## Requisiti

- Windows 10 o Windows 11 (64 bit)
- Connessione a Internet per il primo avvio, la ricerca e il download dei brani

## Aggiornamenti

Spoopify verifica periodicamente la disponibilità di nuove versioni. Quando è disponibile un aggiornamento, nella
barra superiore compare il pulsante **Aggiorna**; la verifica può essere eseguita anche da **Impostazioni › Novità**.

Ogni aggiornamento è firmato digitalmente e viene installato solo se la firma risulta valida. Prima dell'installazione
viene conservata una copia della versione corrente, ripristinata automaticamente in caso di errore.
Le modifiche di ciascuna versione sono riportate nelle [note di rilascio](https://github.com/Daxterminator/Spoopify_Releases/releases)
e in **Impostazioni › Novità**.

## Note

Spoopify è destinato all'uso personale. Scaricare esclusivamente contenuti per i quali si dispone dei diritti necessari.
